# React + Vite

This template provides a minimal setup to get React working in Vite with HMR and some ESLint rules.

This is a responsive movie App using react and tailwindcss

it contains movie cards 

the movie cards contain a dynamic (title, rating, year, description)

it has a dynamic search that gets any searched movie you want

you can filter cards by (year, rating, genre)

In this app you can see the frist five trending movies
